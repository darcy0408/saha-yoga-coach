# Three-to-five-minute demo script

1. **Onboarding (35 seconds):** “Saha asks only what helps shape a practice. It states the safety boundary and stores no identity.” Select consent.
2. **Calibration (30 seconds):** Point out camera height, full-body framing, light, floor space, and the honest demo-mode badge.
3. **Coaching (90 seconds):** Start Steady Start. Read the current pose/status/suggestion/confidence structure. Wait for the injected low-confidence frame and show that correction and timing pause. Click **Easier option**, then **Pause/Resume**.
4. **Control (25 seconds):** Skip through a few poses and show the persistent **Stop now** control.
5. **Progress and privacy (40 seconds):** Stop. Show completed pose count and stability as derived metrics. Explain the routine-change reason and click **Delete all local history**.
6. **Close (20 seconds):** “Java 26 runs the UI, analysis, coaching, persistence, and transparent personalization. Live MoveNet remains a documented next step, not a fabricated claim.”
